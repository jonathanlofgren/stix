# STIX

Design 3D structures from a kit of connectors, poles, and plates — right in your browser.

**→ [Try it at stix.lfgrn.com](https://stix.lfgrn.com/)**

Snap parts together on a 3D grid, track what you own versus what you need, and plan your build layer by layer.

## Run locally

```bash
npm install
npm run dev
```

Then open [localhost:5173](http://localhost:5173).
